### HotkeyGuard — это лёгкое настольное приложение на Python для Windows, позволяющее блокировать определённые сочетания клавиш. Благодаря простому графическому интерфейсу вы можете контролировать случайно активируемые сочетания клавиш и легко управлять нужными вам функциями защиты.

## Обзор

Приложение отслеживает события клавиатуры Windows и блокирует выбранные вами сочетания клавиш. Защита сочетаний клавиш не включается автоматически при запуске приложения — для её активации необходимо нажать кнопку **«Запустить»** в интерфейсе.

## Возможности

- **Блокировка Shift + Delete:** Блокирует сочетание клавиш для безвозвратного удаления файлов.
- **Блокировка F1 в определённых приложениях:** Блокирует клавишу F1 в Chrome, Microsoft Edge, Firefox, Brave, Opera и на рабочем столе Windows / в Проводнике.
- **Выборочная защита:** Вы можете независимо включать и отключать блокировку Shift + Delete и F1 через интерфейс приложения.
- **Сворачивание в системный трей:** Вы можете сворачивать приложение в системный трей.
- **Поддержка нескольких языков:** Поддерживаются турецкий, английский, немецкий, французский, испанский, португальский, русский, японский, упрощённый китайский и корейский языки.
- **Прокручиваемый интерфейс:** Содержимое окна приложения можно прокручивать.

Блокировка F1 действует только в перечисленных выше приложениях. В других приложениях и играх клавиша F1 не блокируется.

## Требования

- Windows
- Python
- Pillow 13.0.0
- pystray 0.19.5

`tkinter`, `ctypes`, `json`, `math`, `os` и `pathlib` входят в стандартную библиотеку Python.

Для использования функции сворачивания в системный трей необходимы как Pillow, так и pystray.

## Установка

1. Скачайте файлы проекта на свой компьютер или клонируйте репозиторий.
2. Откройте папку проекта.
3. Откройте PowerShell в этой папке.
4. Установите необходимые пакеты Python:

```powershell
py -m pip install -r requirements.txt
```

Содержимое файла `requirements.txt`:

```text
Pillow==13.0.0
pystray==0.19.5
```

5. Запустите приложение:

```powershell
pyw .\HotkeyGuard.pyw
```

В качестве альтернативы:

```powershell
pythonw .\HotkeyGuard.pyw
```

## Виртуальное окружение (необязательно)

Вы можете изолировать зависимости Python от других проектов с помощью виртуального окружения:

1. Создайте виртуальное окружение:

```powershell
py -m venv .venv
```

2. Активируйте виртуальное окружение:

```powershell
.\.venv\Scripts\Activate.ps1
```

3. Установите необходимые зависимости:

```powershell
py -m pip install -r requirements.txt
```

4. По завершении работы деактивируйте виртуальное окружение:

```powershell
deactivate
```

## Использование

1. Запустите файл `HotkeyGuard.pyw`.
2. Выберите в интерфейсе сочетания клавиш, которые хотите заблокировать.
3. Нажмите кнопку **«Запустить»**, чтобы активировать защиту.
4. Следите за состоянием защиты через интерфейс приложения.
5. Используйте функцию сворачивания, чтобы переместить приложение в системный трей. Для работы этой функции должны быть установлены Pillow и pystray.

Настройки языка сохраняются по следующему пути:

```text
%USERPROFILE%\.vectordevworks\shortcut_blocker\config.json
```

Этот файл хранит выбранный язык интерфейса. Параметры блокировки сочетаний клавиш можно выбирать в настройках приложения; не следует считать, что эти параметры сохраняются в файле конфигурации.

## Создание EXE-файла (сборка)

Для преобразования Python-приложения в единый EXE-файл используется PyInstaller.

### 2. Переход в папку проекта

Откройте PowerShell в папке проекта.

### 3. Запуск скрипта сборки

Выполните следующую команду, чтобы запустить скрипт `embed_icon.ps1`:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\embed_icon.ps1"
```

**Примечание:** Windows может блокировать запуск сценариев PowerShell из-за политики выполнения. Параметр `-ExecutionPolicy Bypass` используется для обхода этого ограничения. Данная настройка применяется только к запущенному процессу PowerShell. Общесистемные параметры безопасности не изменяются.

### 4. Процесс сборки

Скрипт сборки выполняет следующие действия:

1. Проверяет наличие основного файла Python и файла `assets\icon.png`.
2. Проверяет доступность PyInstaller.
3. Удаляет старые папки `dist` и `build`.
4. Собирает приложение в один EXE-файл без окна консоли.
5. Добавляет папку `assets` и значок приложения в сборку.
6. Проверяет созданный EXE-файл.

### 5. Результат сборки

После успешного завершения сборки EXE-файл будет создан по следующему пути:

```text
dist\HotkeyGuard.exe
```

**Действия при сборке новой версии:**

1. Откройте PowerShell.
2. Убедитесь, что PyInstaller установлен.
3. Перейдите в папку проекта.
4. Запустите скрипт сборки.
5. Найдите созданный EXE-файл в папке `dist`.
