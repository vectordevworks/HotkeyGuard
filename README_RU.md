СтражКлавиш — это лёгкое приложение для Windows, разработанное на Python и предназначенное для блокировки определённых сочетаний клавиш. Простой графический интерфейс позволяет контролировать случайные нажатия сочетаний клавиш и легко управлять выбранными функциями защиты.

## Обзор

Приложение отслеживает события клавиатуры в Windows и блокирует выбранные сочетания клавиш. Защита не активируется автоматически при запуске приложения. Для её включения необходимо нажать кнопку **Запустить** в интерфейсе.

## Возможности

- **Блокировка Shift + Delete:** Блокирует сочетание клавиш Shift + Delete, используемое для окончательного удаления файлов.
- **Блокировка F1 в определённых приложениях:** Блокирует клавишу F1 в Google Chrome, Microsoft Edge, Mozilla Firefox, Brave, Opera, а также на рабочем столе Windows и в Проводнике.
- **Выборочная защита:** Позволяет независимо включать и отключать блокировку Shift + Delete и F1 через интерфейс приложения.
- **Сворачивание в область уведомлений:** Позволяет сворачивать приложение в область уведомлений Windows.
- **Поддержка нескольких языков:** Поддерживаются турецкий, английский, немецкий, французский, испанский, португальский, русский, японский, упрощённый китайский и корейский языки.
- **Прокрутка содержимого окна:** Позволяет прокручивать содержимое окна приложения.

Блокировка F1 действует только в перечисленных выше приложениях. В других приложениях и играх клавиша F1 не блокируется.

## Требования

- Windows
- Python
- Pillow 13.0.0
- pystray 0.19.5

Модули `tkinter`, `ctypes`, `json`, `math`, `os` и `pathlib` входят в стандартную библиотеку Python.

Для использования функции сворачивания в область уведомлений необходимо установить как Pillow, так и pystray.

## Установка

1. Скачайте файлы проекта на свой компьютер или клонируйте репозиторий.
2. Откройте папку проекта.
3. Запустите PowerShell в этой папке.
4. Установите необходимые зависимости Python:

```powershell
py -m pip install -r requirements.txt
```

Содержимое файла `requirements.txt`:

```text
Pillow==13.0.0
pystray==0.19.5
```

5. Запустите приложение:

```powershell
pyw .\HotkeyGuard.pyw
```

В качестве альтернативы можно использовать:

```powershell
pythonw .\HotkeyGuard.pyw
```

## Виртуальное окружение (необязательно)

Для изоляции зависимостей Python от других проектов можно использовать виртуальное окружение:

1. Создайте виртуальное окружение:

```powershell
py -m venv .venv
```

2. Активируйте виртуальное окружение:

```powershell
.\.venv\Scripts\Activate.ps1
```

3. Установите необходимые зависимости:

```powershell
py -m pip install -r requirements.txt
```

4. После завершения работы деактивируйте виртуальное окружение:

```powershell
deactivate
```

## Использование

1. Запустите файл `HotkeyGuard.pyw`.
2. Выберите в интерфейсе сочетания клавиш, которые хотите заблокировать.
3. Нажмите кнопку **Запустить**, чтобы активировать защиту.
4. Отслеживайте состояние защиты через интерфейс приложения.
5. Используйте функцию сворачивания, чтобы переместить приложение в область уведомлений Windows. Для её работы должны быть установлены Pillow и pystray.

Выбранный язык сохраняется в следующем файле:

```text
%USERPROFILE%\.vectordevworks\shortcut_blocker\config.json
```

Этот файл хранит только выбранный язык интерфейса. Параметры блокировки сочетаний клавиш можно настраивать в приложении; не следует предполагать, что эти параметры сохраняются в файле конфигурации.

## Сборка (Создание EXE-файла)

Для преобразования приложения Python в единый EXE-файл используется PyInstaller.

### 1. Установка PyInstaller

Установите PyInstaller версии 6.22.3:

```powershell
py -m pip install pyinstaller==6.22.3
```

### 2. Переход в папку проекта

Откройте PowerShell в папке проекта.

### 3. Запуск скрипта сборки

Выполните следующую команду, чтобы запустить скрипт `embed_icon.ps1`:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\embed_icon.ps1"
```

**Примечание:** Параметр `-ExecutionPolicy Bypass` используется, поскольку Windows может блокировать выполнение сценариев PowerShell в соответствии с установленной политикой выполнения. Этот параметр применяется только к запущенному процессу PowerShell и не изменяет общесистемные настройки безопасности.

### 4. Процесс сборки

Скрипт сборки выполняет следующие действия:

1. Проверяет наличие основного файла Python и файла `assets\icon.png`.
2. Проверяет доступность PyInstaller.
3. Удаляет старые папки `dist` и `build`.
4. Собирает приложение в один EXE-файл без отображения окна консоли.
5. Добавляет папку `assets` и значок приложения в сборку.
6. Проверяет созданный EXE-файл.

### 5. Результат сборки

После успешного завершения сборки EXE-файл будет создан по следующему пути:

```text
dist\HotkeyGuard.exe
```

**Порядок действий при сборке новой версии:**

1. Откройте PowerShell.
2. Убедитесь, что PyInstaller установлен.
3. Перейдите в папку проекта.
4. Запустите скрипт сборки.
5. Найдите созданный EXE-файл в папке `dist`.
